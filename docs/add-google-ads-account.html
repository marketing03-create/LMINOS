➕ Add a Google Ads Account to LMIROS

Reusable checklist. Works for any account under any Gmail. The result looks exactly like the Flexifund detail page — Spend, Impr, Clicks, CTR, Avg CPC, Conversions, plus per-campaign and daily breakdowns.

① Two halves of an account's data

📊 Ad performance

Impr · Clicks · CTR · Avg CPC · Cost · Conversions + daily/campaign breakdown. Comes from the Google Ads API — appears the moment the account is connected.

💰 Revenue / ROAS / Quality%

From LMIROS leads + sales (Zoho + Telegram bot). Fills in once that account's leads also flow into LMIROS with a matching website — same as Flexifund.

② Requirements

What to gather before we start.

#RequirementNotes
1Customer ID (10 digits)Top-right in Google Ads, e.g. 123-456-7890
2Website slug it drivesThe value in Zoho's “Website” column for this account's leads (for per-website ROAS). Unsure? Use a placeholder, refine later.
3Owning Gmaile.g. admin@enquirymail.com — you sign in as this once.
4Gmail allowed on the OAuth apponce per Gmail Add it as a Test user in Google Cloud if sign-in is blocked.
5OAuth client · dev token · encryption keyalready done Shared globally — nothing to do.
⚠️ Two hard rules: it must be a Google Ads account (Meta/TikTok not wired yet), and the Gmail you sign in with must actually have access to it in ads.google.com — otherwise it can't authorize LMIROS to read it.

③ The process — 4 steps

I do

1 · Register the account

npm run seed:ad-account -- google <CUSTOMER_ID> <website_slug> default "Account Name" — creates the row.

You do

2 · Sign in as the owning Gmail

I send you a sign-in URL. Open it → sign in as the Gmail that owns the account → Allow → you land on a “can't be reached” page → copy the code=… from the address bar → send it to me.

I do

3 · Attach its login

npm run gads:set-token -- <CUSTOMER_ID> <code> — encrypts that account's token and stores it on the row (never printed).

I do

4 · Pull its metrics

npm run gads:sync — fetches 90 days. Done.

④ What you'll see — identical to Flexifund

  • /admin/ad-accounts — new row: Spend · Impr · Clicks · CTR · Avg CPC · Conv · Last synced.
  • Click the name → detail page — KPI cards + per-campaign breakdown + daily breakdown, with its own date filter.
  • /admin/spend — its own clickable row.
  • /roas — included in Website / Campaign / Platform breakdowns (revenue + Quality% once its leads/sales are in LMIROS).
  • Auto-refreshes daily via the cron — its login lives encrypted in the shared database, no per-account setup.
💡 Adding several accounts under the same Gmail? You only sign in once per Gmail (step 2). After that, each new account is just steps 1, 3, 4 — register, attach the same login, sync.
