Describe your company's business

How will you use the Google Ads API? (use case)
We have built an internal reporting dashboard (LMIROS) for our own marketing team. Once a day it reads performance metrics — impressions, clicks, cost, and conversions — from our own Google Ads account and stores them in a private internal dashboard, so we can see campaign performance and lead quality in near-real-time instead of waiting for monthly reports. It is read-only reporting; it never creates, edits, or pauses campaigns.
Which API services will you call?
GoogleAdsService (Search / SearchStream) only — read-only GAQL reporting queries selecting campaign, segments.date, and metrics (impressions, clicks, cost_micros, conversions). No mutate/write operations.
How does the integration work? (design)
A scheduled server job runs once per day. It authenticates via OAuth (offline refresh token) for our own account, sends one GoogleAdsService.SearchStream request with a GAQL query for a trailing date window, and writes the returned daily campaign metrics into our private dashboard database. No data is shared externally.

3 Tips for a fast approval

✅ Keep repeating the three magic facts: internal use, our own single account, read-only reporting. That profile is low-risk and exempt from the heavier “Required Minimum Functionality” review.
