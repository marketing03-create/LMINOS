🗺️ LMIROS — Integration Map & Field Reference

Every platform that feeds LMIROS, the exact fields each needs, and which ones you fill once vs. repeat per new account. Use the tables to add ads/agents/users yourself.

SET ONCE platform connection — already done EACH TIME you fill this per new account AUTOMATIC LMIROS creates it for you

The tree — platforms → what they need → LMIROS

LMIROS
│
├── 📣 GOOGLE ADS
│   ├── Platform link  (set once)
│   │   ├── Manager (MCC) account ──▶ Developer Token  (Explorer access = enough)
│   │   ├── Google Cloud OAuth client ──▶ Client ID + Client Secret
│   │   ├── Sign-in (gads:exchange) ──▶ Refresh Token  (default login)
│   │   └── env: GOOGLE_ADS_DEVELOPER_TOKEN, _CLIENT_ID, _CLIENT_SECRET, _REFRESH_TOKEN, _LOGIN_CUSTOMER_ID
│   └── Each ad account  (repeat per account)
│       ├── Customer ID  (10-digit)
│       ├── Website slug  (= the Zoho "Website" value)
│       ├── Owning Gmail  (does the 1 sign-in)
│       └── stored in DB: ad_accounts row + encrypted token
│
├── 📄 ZOHO WORKSHEET  (set once)
│   ├── Self Client (api-console.zoho.com) ──▶ Client ID + Client Secret  (scope ZohoSheet.dataAPI.READ)
│   ├── Sign-in (zoho:exchange) ──▶ Refresh Token
│   ├── The Sheet URL path ──▶ Resource ID  (sheet.zoho.com/sheet/open/THIS_PART)
│   ├── The tab name ──▶ Worksheet Name  (e.g. sheet_1)
│   └── env: ZOHO_CLIENT_ID, _CLIENT_SECRET, _REFRESH_TOKEN, _RESOURCE_ID, _WORKSHEET_NAME
│
├── 💬 TELEGRAM  (set once + per agent)
│   ├── @BotFather ──▶ Bot Token ;  random ──▶ Webhook Secret
│   ├── env: TELEGRAM_BOT_TOKEN, TELEGRAM_WEBHOOK_SECRET
│   └── Each agent: types /start their-email to pair  (self-serve)
│
├── 👥 USERS & AGENTS
│   ├── Staff user ──▶ AUTOMATIC Google SSO on first login  (allowed domain); role set in DB
│   └── Sales agent ──▶ AUTOMATIC from Zoho "Assigned To" on next sync
│
└── ⚙️ CORE INFRA (set once)
    └── Supabase DB + Auth · Encryption key · Cron secret · Redis
        env: DATABASE_URL(_POOLED), NEXT_PUBLIC_SUPABASE_URL/_ANON_KEY, SUPABASE_SERVICE_ROLE_KEY, ENCRYPTION_KEY, CRON_SECRET, REDIS_URL, NEXT_PUBLIC_APP_URL

Table B · Add a NEW Google Ads account EACH TIME

What you gather + do for every new account. (I run the 3 commands; you do the 1 sign-in.)

You provideWhere to find itUsed for
Customer ID (10-digit)Google Ads, top-right (e.g. 123-456-7890)which account to pull
Website slugThe value in Zoho's "Website" column for that account's leadsper-website ROAS (optional; placeholder ok)

Steps: 1) seed:ad-account (me) → 2) gads:exchange sign-in as that Gmail (you) → 3) gads:set-token (me) → 4) gads:sync (me). One sign-in per Gmail covers all accounts under it.

Table D · Add a new Agent or User MOSTLY AUTOMATIC

🔑 The honest "is this hard?" answer: The credentials above are the whole list — nothing more to discover. Agents & users are already self-service / automatic. Adding an ad account is the only one that still runs through 3 commands (I run them) + your 1 sign-in — there's no dashboard button for it yet. Turning that into a no-code "Add account" page in LMIROS is a moderate build (an admin form that walks the OAuth sign-in) — very doable whenever you want it.
